# 开场探索 · 2026-10-15

本轮是三个实时 Shader 视觉小样，不修改正式导航。已选 B 的深色画廊作为落地环境。示例照片仍为 Unsplash 演示，不代表站长作品。音频不作为网页开场默认行为。

已确认范围：用户选择「首次进入门户＋模块短转场」。建议门户首次访问约 4 秒；模块间转场约 0.6–0.9 秒；同次会话不重复完整开场。具体视觉方向仍等待对三个小样的选择。

实现约束：原生 WebGL 片元 Shader，无第三方运行脚本；限制像素密度；只在播放或指针交互时重绘；浏览器失焦暂停；减少动态偏好时直接显示落定画面；无 WebGL 时提供静态照片；可跳过、暂停、拖动时间轴。

本轮预览：`python -m http.server 4175 --bind 127.0.0.1 --directory design-demos/opening`。正式接入时再处理路由衔接、首次访问记忆及移动端性能预算，未选定前不写入主站。

浏览器验证：三个真实 WebGL 场景均编译成功，无 GL 错误或 JavaScript 异常；320/375/414/768 宽度无横向溢出；跳过、减少动态偏好和无 WebGL 静态回退通过。测试使用浏览器软件图形渲染，尚未对真实手机 GPU 的帧率作承诺。
