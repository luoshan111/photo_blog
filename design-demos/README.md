# 设计方向预览

三份原型分别存放在独立文件夹。它们用于选择版式与浏览体验，不是最终发布站点。

- `magazine/index.html`：图文杂志，摄影与文章并列。
- `gallery/index.html`：摄影画廊，图像优先。
- `directory/index.html`：个人目录，入口优先。

每份原型包含门户、摄影、博客的视图。演示内容和外部图片不代表站长真实作品。正式版本将按模块拆分，详见 `../docs/requirements.md`。

入口修订：三份门户现在平级展示「摄影作品」和「技术博客」，门户不再以大幅照片为主。技术博客单独保存在 `technical-blog/index.html`，采用独立页面；大图与相册保留在摄影页面。

可以直接在浏览器打开 HTML。示例图片已保存到 `assets/`，无需依赖外部图片服务；正式站点将换为用户提供的作品。
