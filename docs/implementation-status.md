# 首期实现状态

已实现：门户与两个独立模块入口、模块显示开关、介绍与联系配置；摄影相册、图库、说明、全屏浏览（键盘/触摸）；技术文章列表、分类标签、正文与目录；手机适配、键盘焦点、图片优化、404、可配置搜索/分享元信息；草稿预览、发布撤下、源文件备份。

内容仍为演示。真实头像、个人资料、摄影作品、技术文章及域名待补充。只有填写真实域名并构建后才生成站点地图与完整分享图片地址。预览服务器仅提供公开构建目录，草稿预览单独运行。

第二批已实现：技术博客全文搜索、按年月归档、构建时语法高亮、代码复制。搜索和归档遵循发布过滤，未知代码语言安全降级为纯文本。

2026-10-23 博客写作升级：文章可使用单个 Markdown 文件和开头的 YAML 信息，旧 JSON 配套文章继续兼容；替换为 CommonMark 解析，支持正文图片、表格、行内及独立 LaTeX 公式，同时保留代码高亮、复制、目录及原始 HTML 转义。本地静态配图生成保留透明度的响应式 WebP，只输出已收录文章实际引用的素材，草稿配图只进入草稿预览。公式使用模块内 KaTeX 0.19.0 和字体，无 CDN 或构建时联网依赖。

提供 `src/modules/blog/templates/post.md` 写作模板，以及 `/blog/posts/markdown-guide/` 示例文章。8 项原有构建测试、5 项 Markdown 测试、13 项浏览器检查通过；320/375/414/768/1440 宽度均无页面横向溢出，图片、表格对齐、长公式滚动、MathML、字体加载、错误公式回退和公式资源按需加载已验证。

已接入用户选定的三种实时 Shader：C 为首次门户开场，A 为摄影模块入场，B 为联系方式区域转场。提供会话记忆、页脚手动重播、跳过/Escape、焦点管理、减少动态与无 WebGL 回退，以及加载失败时自动解除遮挡的保护。所有效果仅使用本地网站素材，无视频或远程运行脚本依赖。

博客入场追加黑白灰像素 Shader 与银白扫描流光，透明像素逐步揭开真实页面，默认 1.6 秒；从其他模块进入博客首页或直接首次打开时播放，刷新、浏览器后退和博客内跳转不重复播放。首页页脚提供「重播入场」。专属资源在 `src/modules/blog/motion/`，时长由 `site.json` 的 `motion.blogSeconds` 控制。8 项构建测试及 16 项浏览器断言通过，包括真实 Shader 灰阶与透明度采样、原生导航、移动布局、焦点与滚动释放、跳过/Escape、减少动态、无 WebGL 和渲染模块加载失败回退。

博客像素入场增加错峰闪亮的银白光点、短十字光线与柔和光晕；仅出现在尚未揭开的暗部，随揭幕结束退去。光效使用原有播放进度驱动，暂停、重播和减少动态继续沿用原有机制。新增效果后 16 项浏览器断言再次通过。
