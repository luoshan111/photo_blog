# 三种设计方向

受众：朋友、面试官。目的：快速了解站长、进入摄影与博客。内容偏好：博客简洁，摄影有设计感。本轮没有真实身份与作品素材。

| 方向 | 结构 | 设计来源 | 重点 |
| --- | --- | --- | --- |
| A 图文杂志 | 刊头、图文并列 | 秒数轮盘：18 % 20 + 1 = 19，Swiss 黑白风格；转化为中文图文杂志 | 摄影与写作同等可见 |
| B 摄影画廊 | 左介绍右大图、深色作品空间、暖白阅读页 | 现实参照 Alec Soth 的作品优先组织方式，https://alecsoth.com/photography/ | 把空间留给照片 |
| C 个人目录 | 中文索引、细线与留白、错落画廊 | 原研哉的信息减法与白盒画廊思路；仅作为设计方法启发 | 访客快速找到入口 |

建议组合：C 的门户 + B 的摄影 + 简洁博客。组合仍须用户选定，不据此自动视为批准。

原型支持模块切换、照片弹窗、左右切换和示例文章。真实身份、作品、发布流程和正式路由在方向确定后实现。三个方向单独保存，仅预览用照片共用 `design-demos/assets/`；正式模块按需求文档分目录。

## 素材来源

Unsplash 演示图片，非用户作品。已下载为本地预览素材；图片源地址按文件名对应 `https://images.unsplash.com/<photo-id>`。不用于冒充用户履历或个人摄影作品。
